GitHub 云备份 推荐
填一次仓库和 Token，之后改动会自动推送；换浏览器 / 换设备点「拉取」即可原样恢复。
Token 申请：github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens，只对这一个私有仓库给 Contents 读写。Token 只存在你自己的浏览器里。
自动快照 · 最近 6 次改动，误删可回滚
数据保存在当前浏览器的本地存储里，换浏览器、换设备、清理缓存都会丢失。
开了 GitHub 云备份后就不用管了：本地每次改动会推一份到你的私有仓库，链接重发导致本地缓存丢失时，重新打开会自动从 GitHub 拉回。
